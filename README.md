# Territory Planner

iOS-приложение для планирования виртуального покрытия территории: генерация маршрутов (сетка, спираль, змейка, кольца, свой), учёт покрытия, воспроизведение с шагами и паузами, импорт/экспорт GPX и интеграция с инструментами симуляции геопозиции Apple (Xcode Simulate Location, `xcrun simctl location`) — для тестирования **собственных** приложений.

SwiftUI · MapKit (iOS 17 API) · Core Location · Observation (MVVM) · без сторонних зависимостей.

## Требования

| | |
|---|---|
| Xcode | 16.0+ (проект использует synchronized folders, objectVersion 77) |
| iOS | 17.0+ (iPhone и iPad) |
| Swift | 5.9+ (режим языка Swift 5) |

Xcode 15: установите [XcodeGen](https://github.com/yonaskolb/XcodeGen) и выполните `xcodegen generate` — в корне лежит `project.yml`, он пересоздаст `.xcodeproj`.

## Запуск

1. Откройте `TerritoryPlanner.xcodeproj`.
2. Target **TerritoryPlanner** ▸ Signing & Capabilities ▸ выберите свою Team (для устройства). Для симулятора подпись не нужна.
3. Run (⌘R).

Новые файлы, добавленные в папку `TerritoryPlanner/`, подхватываются автоматически — правка `.pbxproj` не нужна.

## Как пользоваться

1. **Центр области** — режим «Центр» (по умолчанию), коснитесь карты. Или «Моя позиция».
2. **Радиус** и **шаблон** — вкладка «Маршрут». Предпросмотр перестраивается автоматически (отключается в Настройках).
3. **Старт** — режим «Старт» на карте. Для сетки/змейки выбирается зеркальный вариант, который начинается ближе к старту; для спирали/колец шаблон поворачивается к старту. Если старт вне шаблона — добавляется подход.
4. **Свой маршрут** — режим «Точки», касайтесь карты. Отрезки уплотняются до заданного шага.
5. **Воспроизведение** — панель всегда видна: ⏮ шаг назад, ⏹ стоп, ▶/⏸ старт/пауза/продолжить, ⏭ шаг вперёд, ×N ускорение.
6. **Точки** — список с правкой: изменить координаты/паузу/имя, вставить, удалить, переупорядочить, развернуть, уплотнить, пауза для всех, «Перейти сюда».
7. **GPX** — импорт (Файлы), экспорт в трёх форматах, копирование команды `simctl`, демо-маршрут.

## Алгоритмы

- **Сетка / змейка.** Квадратная решётка с шагом `s` в локальной метрической плоскости, опционально обрезанная кругом. Сетка — каждый ряд в одном направлении, змейка — бустрофедон. Ориентация (горизонт./верт.), реверс, поворот на произвольный угол.
- **Спираль.** Архимедова r = bθ, b = s/2π — соседние витки ровно в `s` друг от друга; точки по дуге с шагом `s` (ds = √(r²+b²)·dθ).
- **Кольца.** Концентрические окружности через `s`, на кольце ⌈2πr/s⌉ точек (мин. 6), снаружи внутрь или наоборот.
- **Лимит точек.** При превышении шаг растёт в √(N/limit) раз до сходимости (число точек ∝ (R/s)²); либо маршрут обрезается — по выбору.
- **Покрытие.** Площадь режется на клетки размером с радиус покрытия; клетка покрыта, если центр попал в «пятно» позиции. Между позициями пятно протягивается вдоль отрезка — результат не зависит от частоты тиков и от пошагового режима. Оверлей склеивается в горизонтальные полосы (run-length), поэтому полигонов порядка числа рядов, а не клеток.
- **Воспроизведение.** Интегратор с тиком ~66 мс: симулированное время = реальное × множитель; время тратится сначала на паузу в точке, затем на движение к следующей; за один тик можно пройти несколько точек без потери событий. ETA = оставшаяся длина / скорость + оставшиеся паузы.

## Интеграция с инструментами Apple (тестирование своих приложений)

iOS не позволяет приложению подменять геопозицию системы — и это приложение этого не делает. Симуляция для других приложений идёт только через поддерживаемые Apple механизмы разработчика:

**Xcode ▸ Simulate Location (симулятор и устройство, подключённое к Xcode)**
1. Экспортируйте маршрут в формате **Xcode (wpt + time)**.
2. Добавьте `.gpx` в проект своего тестируемого приложения.
3. Запустите его из Xcode и выберите файл в **Debug ▸ Simulate Location** (или в схеме: Edit Scheme ▸ Run ▸ Options ▸ Default Location).

Xcode берёт скорость из разницы `<time>` между точками; пауза кодируется повтором точки с более поздним временем.

**iOS Simulator из Терминала (Xcode 14+)**
```bash
xcrun simctl location booted start --speed=5.00 37.334900,-122.009000 37.335100,-122.008500 ...
xcrun simctl location booted clear
```
Кнопка «Скопировать команду simctl» собирает её из текущего маршрута (паузы simctl не поддерживает; >2000 точек прореживаются).

**Сверка с планом.** В Настройках переключите источник на **Core Location**: приложение отмечает достигнутые точки и покрытие по реальным фиксам — удобно, чтобы проверить, что системное воспроизведение совпадает с планом.

## Формат GPX

- Импорт: GPX 1.0/1.1, `trkpt` → `rtept` → `wpt` (по приоритету), `ele`, `time`, `name`.
- Валидация: корень `<gpx>`, корректный XML (ошибка с номером строки), lat ∈ [−90, 90], lon ∈ [−180, 180], ≥ 1 точки, порядок времени, смешанные типы точек — с понятными сообщениями.
- Повторы координаты с временем сворачиваются в паузу; дубли без времени отбрасываются.

## Сохранение

Настройки, область, свои точки и маршрут сохраняются в `Application Support/planner-session.json` (атомарная запись, с debounce при движении слайдеров) и восстанавливаются при запуске.

## Ограничения

- Локальная проекция равнопромежуточная — погрешность < 1 % для областей до десятков километров (максимальный радиус в UI — 10 км).
- Маркеры отдельных точек рисуются для маршрутов до 400 точек; длиннее — только линия.
- Сборка проверялась статическим ревью: Swift-компилятора в среде генерации не было. Если Xcode укажет на мелкую несовместимость API — она будет локальной (одна строка), архитектура от этого не зависит.
